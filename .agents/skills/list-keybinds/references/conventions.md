# Keybinds Conventions

## Split Terminology

Avoid "vertical" or "horizontal" due to tool-specific ambiguity. Use:

* Side-by-side: panes placed left and right
* Top-bottom: panes placed above and below

## Formatting

Use standard tables with relative source links:

```markdown
[Source](path/to/config)

| Keybinding | Action |
| :--- | :--- |
| `Key` | Description |
```

## Metadata

Identify the Leader, Prefix, or Modifier key (e.g., Super, Space, Ctrl+b) at the start of each section.
